# Ссылки для запуска

Все адреса, которыми открывается приложение в разных конфигурациях. Новый параметр адреса или новая конфигурация добавляются сюда.

Сначала запустите dev-сервер из корня проекта:

```powershell
.\scripts\stella.ps1 dev
```

Остановить: `Ctrl+C` в том же терминале. Остальные команды — в [docs/context/DEV_WORKFLOW.md](docs/context/DEV_WORKFLOW.md).

## Основные конфигурации

| Конфигурация | Ссылка | Что нужно |
| --- | --- | --- |
| Локальный сценарий | <http://127.0.0.1:5218/stella/> | Камера запустится только с Logitech BRIO |
| Приветствие на стартовом экране | <http://127.0.0.1:5218/stella/?greeting=1> | — |
| Любая камера | <http://127.0.0.1:5218/stella/?camera=any> | Разрешить камеру в браузере при первом открытии |
| Любая камера и приветствие | <http://127.0.0.1:5218/stella/?camera=any&greeting=1> | То же |
| Микрофон: ответы голосом | <http://127.0.0.1:5218/stella/?mic=1> | Chrome или Edge, интернет, разрешить микрофон при первом включении |
| Микрофон и приветствие | <http://127.0.0.1:5218/stella/?greeting=1&mic=1> | То же |
| Микрофон, приветствие и любая камера | <http://127.0.0.1:5218/stella/?camera=any&greeting=1&mic=1> | То же и разрешение на камеру |
| Мастер (стендовый режим) | <http://127.0.0.1:5218/stella/?master=1> | Запущенный MASTER на `http://127.0.0.1:8842` |
| Мастер с приветствием | <http://127.0.0.1:5218/stella/?master=1&greeting=1> | То же |
| Мастер с любой камерой | <http://127.0.0.1:5218/stella/?master=1&camera=any> | То же и разрешение на камеру |
| Мастер с панелью оператора | <http://127.0.0.1:5218/stella/?master=1&operator=1> | Запущенный MASTER |

Микрофон включается сам, когда голос за кадром договорил реплику экрана, который ждёт ответа: онбординг, вопросы VK Видео и MAX. Пока он включён, вверху экрана виден значок микрофона. Что можно сказать: «поехали», «начать», «давай»; слова ответа с карточки или его номер — «первый», «вторая». На стартовом экране микрофон не включается, продукт выбирается касанием, с приветствием и без него. Шаг согласия на фото тоже отвечается только касанием. Речь распознаёт браузер: Chrome и Edge отправляют звук на свои серверы. В стендовом режиме `?master=1` микрофона нет.

Адрес MASTER для dev-сервера задаётся переменной окружения `STELLA_MASTER_TARGET` до запуска; по умолчанию `http://127.0.0.1:8842`. Без MASTER режим `?master=1` не является автономным демо.

## Запись экрана

Для скринкаста приложение открывается в отдельном Chrome, настроенном под запись:

```powershell
.\scripts\stella.ps1 record
```

Если dev-сервер не запущен, задача сама запускает его в новом окне PowerShell и ждёт до 40 с; это окно остаётся после записи, сервер останавливается в нём `Ctrl+C`.

По умолчанию открывается `?camera=any&greeting=1&mic=1`. Другие параметры адреса — в кавычках: `.\scripts\stella.ps1 record "camera=any&greeting=1"`.

В этом Chrome отключены: отслеживание перекрытия окна (страница рисуется, даже когда её закрывает панель или окно программы записи), приглушение фоновых окон, вывод живого видео камеры в аппаратный оверлей, передача кадров камеры текстурами видеокарты. Обычный Chrome не затрагивается: у окна записи свой профиль в `%TEMP%\chrome-stella-rec`, камеру и микрофон в нём нужно разрешить один раз. Перед повторным запуском закройте все окна этого профиля: настройки читаются только при старте браузера, задача об этом напомнит.

Камеру в один момент держит одна программа. Перед запуском закройте вкладку с приложением в обычном Chrome и другие программы с камерой: иначе страница получит «Device in use» и на карточке будет «Камера недоступна». Если камера занята, задача не запустится и назовёт программу.

## Предпросмотр сцен

Сцена повторяется по кругу, без прохождения сценария.

| Сцена | Ссылка |
| --- | --- |
| Теги одного ответа VK Видео | <http://127.0.0.1:5218/stella/?reveal=series> |
| То же с тегами-заливкой | <http://127.0.0.1:5218/stella/?reveal=series&tagLook=solid> |
| Discovery «пульс + нейросеть» | <http://127.0.0.1:5218/stella/?discovery=generation> |
| Этап сканирования | <http://127.0.0.1:5218/stella/?discovery=scan> |
| Сканирование и далее по сценарию; без камеры проверка фото показывает чёрный квадрат | <http://127.0.0.1:5218/stella/?discovery=sequence> |
| Сканирование со съёмкой и проверка фото, любая камера | <http://127.0.0.1:5218/stella/?camera=any&discovery=sequence> |

Фото, одобренное на экране проверки кнопкой «Продолжить», dev-сервер сохраняет в папку [PhotoStorage](PhotoStorage/README.md) в корне проекта.

В `?reveal=` подставляется id ответа из `integrations/master/stella-candidate/src/content/vkVideo.ts`, например `series`, `standup`, `interview`.

## Отладка

| Что | Ссылка |
| --- | --- |
| Журнал звуковых эффектов в консоли браузера, строки `[stella-sfx]` | <http://127.0.0.1:5218/stella/?sound=debug> |
| Журнал закадрового голоса в консоли браузера, строки `[stella-voice]` | <http://127.0.0.1:5218/stella/?voice=debug> |
| То же, что журнал микрофона ниже, и дополнительно что услышал и какую кнопку нажал | <http://127.0.0.1:5218/stella/?greeting=1&mic=debug> |
| Исходные страницы прототипа Claude Design, сервер `.\scripts\stella.ps1 design` | <http://127.0.0.1:5219/> |

Диагностика камеры пишется в консоль браузера всегда, строки `[stella-camera]`.

Журнал микрофона при `?mic=1` тоже пишется всегда, строки `[stella-mic]`: `on` — начал слушать, `failed <причина>` — сбой, попытка повторится, `off <причина>` — выключился, `unavailable` — браузер не распознаёт речь. Причины: `answered` — ответ принят, `left` — экран сменился или пауза, `no-answer` — 30 с без ответа, `not-allowed` — нет разрешения на микрофон, `network` — нет связи с сервером распознавания, `aborted` — распознавание занято другой вкладкой или прервано браузером, `audio-capture` — микрофон недоступен.

## Параметры адреса

Параметры сочетаются через `&`.

| Параметр | Действие | Где работает |
| --- | --- | --- |
| `master=1` | Стендовый режим: сценарий ведёт MASTER | dev-сервер и сборка |
| `greeting=1` | Приветствие на стартовом экране | dev-сервер и сборка |
| `greeting=0` | Отключает приветствие, которое в тестовой сборке включено по умолчанию | только тестовая сборка |
| `mic=1` | Микрофон: включается после реплики голоса на онбординге и вопросах, сказанное нажимает названную кнопку | dev-сервер и сборка; только локальный сценарий, не `master=1` |
| `mic=debug` | То же и в журнале микрофона видно, что услышано | то же |
| `camera=any` | Камера браузера по умолчанию вместо BRIO, картинка без поворота на 90° | только dev-сервер; в тестовой сборке включено всегда |
| `operator=1` | Панель состояния и ссылки оператора в стендовом режиме | только dev-сервер |
| `reveal=<id ответа>` | Предпросмотр сцены тегов | только dev-сервер |
| `discovery=generation`, `scan`, `sequence` | Предпросмотр сцен Discovery | только dev-сервер |
| `tagLook=solid` | Теги с заливкой вместо градиентной рамки | dev-сервер и сборка |
| `sound=debug` | Журнал звуковых эффектов в консоли | dev-сервер и сборка |
| `voice=debug` | Журнал закадрового голоса в консоли | dev-сервер и сборка |
| `service=1` | Служебный: оболочка стенда ставит приложение на паузу. Вручную не открывается | dev-сервер и сборка |

На стенде приложение открывает оболочка из `integrations/stand`; оттуда действуют только параметры с пометкой «сборка».
