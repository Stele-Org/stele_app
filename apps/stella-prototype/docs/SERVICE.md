## Работа

В 3D: открыть http://localhost:8770/viewer/show/, в «Источники стенда» нажать **«Подойти к стеле»**. Включается прогулка с камерой перед экраном на высоте глаз. ЛКМ выбирает ответы на самой стеле; при Pointer Lock используется прицел, при отказе браузера — обычный курсор (ПКМ поворачивает взгляд). «Общий вид» возвращает обзор. После обновления сборки перезагрузить уже открытую вкладку Viewer. В обзорном режиме клики вращают модель и не передаются анкете, как и у MAX.

Запуск всего стенда: `apps/STARTUP/Start.bat`. Мастер: http://localhost:8770/. Пункт «Стела · VK и MAX» открывает http://localhost:8770/service/presentation.html?instance=vk-stella — интерактивный поток того же источника, который передаётся в Spout. `/stella/` — отдельная локальная сессия для диагностики, не зеркало текущего экрана. Интернет при работе не нужен.

Источник `vk-stella`, appId `stella`, назначение `SCREEN_STELLA` сохранены. Program 1080 × 1920, транспорт 1080 × 1922; верхние две строки — служебный stamp, полезная область `[0,2,1080,1920]`. Spout sender сохраняет прежнее имя `VK-<project-prefix>-vk-stella-program`. NDI не включён. Пользовательский профиль сохраняется; внутренний холст пропорционально вписывается в него.

React/DOM целиком захватывается Chromium через существующий game-page-host, затем GPU → Spout. WebRTC preview использует тот же worker, до двух ROI и 10 запросов кадров/с; второй игровой экземпляр не создаётся. Pointer API проверяет clientId, generation и mappingRevision. Ввод работает в presentation и через существующий raycast Viewer в режиме прогулки. Пауза блокирует ввод, приостанавливает CSS-анимации и отсчёт имитации сканирования; служебный heartbeat продолжается. Cancel не считается выбором ответа. Перезапуск источника сбрасывает анкету, перезагрузка presentation — нет.

MAX: два вопроса и назначение миссии. VK Видео: два вопроса предпочтений, выбор Discovery, необязательная имитация фото с выбором пола. Прототип **не передаёт результат на левую/правую стену**, не использует камеру; ранее существовавший `/flow/` остаётся отдельным сценарием. Белая сущность прежнего worker больше не является содержимым стелы. Связь анкеты со стенами — отдельная задача.

## Сборка и обновление

В `artifacts/stella-prototype`: `npm ci --ignore-scripts`, `npm run typecheck`, `npm test`, `npm run lint`. Для сборки рекомендуется Node.js 24 LTS (Vitest не объявляет поддержку Node 25).

Из корня: `python artifacts/web/tools/build_stella_prototype.py`, `python artifacts/web/tools/build_service.py`; при изменении Viewer — `python artifacts/web/tools/build_bundle.py`. Runtime создаётся сборщиками, документация и мастер-конфиги сохраняются. Файлы вне manifest не удаляются. Изменённый вручную runtime блокирует перезапись. Сборщик полного portable включает `apps/stella-prototype`; LAN digest также учитывает приложение.

Для изменения маршрутов/host обязателен штатный Stop → Start через apps/STARTUP. Для обновления только React/worker после сборки перезапустить только `vk-stella` из мастера. Проверка запуска — `apps/STARTUP/Check.bat`, затем короткая проверка потока и ввода.

[Результаты установки](../../../artifacts/reports/stella-prototype-20260927/README.md). Аппаратный touch/LED, художественная оценка и целевые FPS требуют отдельной приёмки.
