По прямому запросу пользователя 01.10.2026 для следующих визуальных итераций используется **http://localhost:5175/stella/**. Это исходный React/Vite-прототип с текущим LumiCells и native-кнопками, самостоятельной анкетой и горячим обновлением. В адресе нет service=1: сообщения паузы мастера не управляют этой сессией. Перезагрузка страницы начинает новую анкету. BroadcastChannel ограничен этим отдельным origin, события не смешиваются с localhost:8770.

Запуск из проекта: `artifacts/stella-prototype/Start-Local.bat`. Повторный запуск использует уже работающий сервер с проверкой своего HTTP-заголовка; чужой порт не перехватывается. Браузер автоматически не открывается. Альтернатива для разработки: в artifacts/stella-prototype выполнить `npm run dev`, открыть тот же адрес; Ctrl+C останавливает foreground-процесс. Требуются существующие node_modules и Node.js; зависимости не скачиваются при запуске. Логи фонового запуска — artifacts/workspace/runtime/stella-local.

Прямое указание об отдельной странице является исключением из прежнего требования запускать все игры только с мастером. Этот сервер привязан к127.0.0.1:5175; мастер/Electron/3D/WebRTC/Spout не запускаются и не перезапускаются. Vite читает только исходники стелы, выбранный брендовый пакет и закреплённые исходники LumiCells; корень проекта и secrets не разрешены. Имеющийся мастер продолжает работать независимо.

Для визуальной правки изменять artifacts/stella-prototype/src и сохранять файл; Vite доставляет изменение через hot reload, сборка runtime/архива и интеграция в apps/ не нужны. Штатную сборку и обновление vk-stella выполнять только при следующем явном запросе интеграции в рабочий стенд. Дизайн и сценарии этой подготовкой не менялись. Визуальный просмотр выполняет пользователь по действующему правилу AGENTS.
