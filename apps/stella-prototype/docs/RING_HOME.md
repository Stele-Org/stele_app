# Стартовый экран стелы на кольце LumiCells

Исторический первый шаг 0.4.0, 01.10.2026. Действующий интерфейс всех экранов заменён интеграцией [0.5.0](RING_INTERFACE.md).

Интеграция 0.4.0, 01.10.2026. Первая малая итерация дизайна: только выбор продукта. Вступления, вопросы, результаты, фото и условия пока сохраняют предыдущую вёрстку.

## Рендер и ввод

Внутри React используется оригинальный `<lumi-cells>` из закреплённого LumiCells commit `1007717d72cfd9d768d4b9a3f7fc80a126e49c51`, пресет `reference`, режим `sphere`. Vite собирает исходную библиотеку из локального checkout, указанного в `tsconfig.app.json`; сетевой зависимости нет. Исходные shader/DOM bindings не изменяются. CUBES-маска, Discovery и кольцо на стыке не используются как персонаж этого экрана.

Конфиг — [ring-home-config.ts](../../../artifacts/stella-prototype/src/components/ring-home-config.ts): исходные радиус, отверстие, дыхание и вращение сохранены; композиционный центр `[0,-1]`, 38 клеток на короткой стороне, softness=0, halo=0.08, bloom=0.28, haze=0. Палитра адаптирована к сине-фиолетовому референсу и проектным цветам MAX. MAX/VK Видео используют оригинальные `primary-white` SVG; пояснение MAX — Max Sans Regular. Это проектный макет, не готовый UI-kit брендбуков.

Две карточки располагаются друг под другом: верхняя y=790…998, нижняя y=1020…1228. Ввод целиком выше границы y=1280 на логическом холсте 1080×1920. Нижняя треть содержит только визуальное поле. Уменьшенное превью масштабирует контент внутри нескалированного host кольца, чтобы оригинальные `client`-координаты DOM-привязок совпадали с местом касания. В рабочем источнике сохраняются 1080×1920 и транспорт 1080×1922.

Карточки используют оригинальные `data-lc-influence="light"`, `data-lc-color`, `data-lc-color-mix`, `data-lc-strength`, `data-lc-falloff`, `data-lc-padding` и `data-lc-pulse="click"`. Под заголовком — `shadow`. Глобальные pointer/click-импульсы выключены, чтобы один тап не создавал два импульса. `lift` не включён.

Первое подтверждённое нажатие блокирует повторный выбор и запускает 420 ms обратной связи, затем ровно один раз открывает прежнее вступление выбранного продукта. Reduced motion убирает ожидание. Пауза сервиса останавливает LumiCells и сохраняет остаток ожидания; уход с экрана отменяет callback. Оригинальный Web Component освобождает экземпляр при отключении от DOM.

## Доставка к рабочему экрану

React сообщает только владельца кадра через `data-stella-renderer`: `ring-home` или `shared`. На входе `stella-worker.js` скрывает и не рисует старый общий фон; на последующих экранах возобновляет его. Старый renderer остаётся готов к возврату, но на входе не выполняет второй фоновый проход. Кольцо имеет собственный авторский RAF; Spout по-прежнему получает захват существующей страницы через прежний native host.

`data-stella-ring-state=ready` появляется после оригинального `lc-ready`, который библиотека отправляет после успешно нарисованного GPU-кадра. До этого worker не объявляет стартовый экран готовым. `lc-error/lc-fallback` переводят его в ошибку вместо ложной готовности. Пауза перед первым кадром задерживает готовность до возобновления.

Применение: штатные сборщики стелы и Stand Service, затем перезапуск только `vk-stella`. Основной адрес — [рабочая стела](http://localhost:8770/service/presentation.html?instance=vk-stella); [отдельная сессия](http://localhost:8770/stella/) не зеркалит состояние рабочего источника.

Технические проверки, generation и ограничения — [отчёт](../../../artifacts/reports/stella-ring-home-20261001.md). Художественное совпадение, плавность и физическая досягаемость ожидают пользовательского скриншота/отзыва. Голос и сквозная передача метаданных этой итерацией не подключены.
