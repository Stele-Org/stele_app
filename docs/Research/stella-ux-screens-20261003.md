## Что задаёт визуальный язык

- Тёмная длинная поверхность, брендовый свет и мелкая читаемая сетка. Вопросы/ответы сосредоточены наверху, низ преимущественно декоративный. Большое пустое пространство снизу намеренно; его не нужно заполнять интерфейсом.
- VK Видео: насыщенные синие карточки, белые подписи, крупные предметные/фотографические композиции. Красный — основные CTA; материал тегов тёмный с цветной обводкой. ВSVG10 основная заливка карточки #0040FF, фото-CTA14 #FF2B42. Это значения конкретного экспорта, не автоматическое переопределение общих брендовых токенов.
- MAX: фиолетовый/пурпурный свет, градиентные карточки и плашки, тонкие светящиеся границы, объёмные иллюстрации/персонаж. Общий layout совместим с VK Видео, материалы и графика различаются.
- Ответ читается вместе с изображением; картинка занимает существенную часть карточки, а текст закреплён снизу слева. Это не маленькая иконка рядом с длинным текстом.
- У тегов18/19 пространственная композиция: крупность, перекрытия, размытие отдельных ближних элементов, намеренное обрезание границей экрана. Размытие не относится автоматически ко всей фоновой сетке. Из статичного кадра нельзя вывести траекторию, скорость, тайминг/пружину или требование непрерывной реальной3D-сцены.
- Пиксельная рука/кольца касания обозначают взаимодействие; надпись «ПОЕХАЛИ» — голосовую альтернативу. Наличие этих слоёв не подтверждает реализованный голосовой ввод.

## Размеры, которые можно взять из SVG

ВSVG10 синие карточки примерно468×280, радиус60; левая колонкаX45.27, праваяX556–558.5, рядыY549/869.17. «Назад» примерно265×120 поX407.34/Y1205.34. ВSVG8 MAX карточки465×280; третья поX307.5/Y872.727, то есть центрирована. ВSVG14 CTA415×140 поX332.5/Y750; Skip358.319×120 поX360.84/Y930. Это измерения элементов выбранных SVG, не единый обязательный токен для всех состояний.

Часть кнопок «Назад» заканчивается околоY1312–1325, чуть ниже прежней границы2/3=1280. При будущем переносе это нужно согласовать с физической интерактивной зоной; молча расширять её по одному макету нельзя.

## SVG как источник ассетов

Тегов text нет во всех22SVG: надписи переведены в path. Поэтому SVG не содержит готовой текстовой модели, локализации или accessible names; сценарные подписи должны оставаться данными приложения. По XML не определяем гарнитуру как подтверждённый факт.

ВSVG найдено32 уникальных встроенных PNG по SHA. Изображения включены через data URI/pattern/clip; внешних href за пределами документа не найдено. Есть маски, градиенты, blur-фильтры и foreignObject (например MAX8/18): упрощённая конвертация может потерять материал. Весь экран не стоит трактовать как один небольшой векторный значок — только вVK10 около4500 rect фоновой сетки.

Два исходных embedded PNG декодированы без изменения пикселей для проверки: [самолёт/багаж](stella-ux-screens-20261003/STELLA-10-embedded-sample.png), [ID](stella-ux-screens-20261003/STELLA-8-embedded-sample.png). Они отделены от надписей; для остальных ассетов это надо проверять индивидуально. В runtime ничего не копировалось. Экспорт не содержит SMIL animate/animateTransform/animateMotion/set или script; анимационный контракт из него не следует.

## Сценарная трактовка и открытые различия

Вероятная логика по смыслу: выбор продукта→брендовый вход→инструкция→вопросы→ответ/теги→следующий вопрос/результат; для VK Видео есть фото/подготовка/силуэт. Это реконструкция, а не утверждённые связи макета.

ВопросыVK10–13 содержат четыре самостоятельных формулировки, текущий код — три других. Нельзя автоматически превращать картинки в новую систему весов и рекомендаций. Начальные экраны2/21 и MAX6/7 — альтернативы; приоритет не указан. В наборе нет отдельного экрана выбора пола, условий, прочих MAX-миссий и текущего QR-финала — отсутствие изображения не означает отмену функции. Результат3 предлагает другую миссию, а действующая кнопка возвращает домой; это сценарное отличие, а не только оформление.

[Отдельная сверка с кодом](../../artifacts/reports/stella-ux-reference-study-20261003.md). Визуальная приёмка действующей сборки не выполнялась; изучение исходных экранов завершено. Прежнее пользовательское правило ухода ответа с последними тегами сохраняется: статичные18/19 его не отменяют.
