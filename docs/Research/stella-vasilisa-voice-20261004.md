# Василиса: голосовые подсказки Стеллы

Дата: 04.10.2026. Scope: самостоятельная Стелла в D, без переноса в F.

## Решение

Для фиксированных текстов выбран Qwen3-TTS-VC `qwen3-tts-vc-2026-01-22`. Enrollment создаёт голос по образцу, это не обучение собственной модели. Голос привязан к target_model; существование TTS-клона не означает готовность голоса Omni. Синтез выполняется при подготовке контента; браузер получает локальные WAV и не обращается к Alibaba.

Основание: [официальное руководство Qwen voice cloning](https://www.alibabacloud.com/help/en/model-studio/voice-cloning-user-guide), обновлено 28.09.2026. Поддерживается русский язык, mono WAV PCM16 ≥24кГц, до60с и10МБ. Рекомендуются10–20с. Наш образец24,609с укладывается в допустимый максимум. Create возвращает voice; отдельного обучения/polling для Qwen-TTS не требуется. В образце технически проверены формат, продолжительность, уровень и длинные паузы; сходство тембра требует прослушивания пользователем.

Пять предоставленных записей объединены FFmpeg в порядке вопрос → варианты1–4. Исходники сохранены. [FFmpeg concat filter](https://ffmpeg.org/ffmpeg-filters.html#concat) реализует соединение, штатный resampler приводит PCM24/48кГц к PCM16/24кГц. Качество не улучшается искусственным повышением частоты.

## Воспроизведение

Выбран Howler2.2.4 (MIT), типы @types/howler2.2.12. Готовая библиотека отвечает за загрузку, play/pause/stop/unload и разблокировку media. React hook только согласует текущую реплику со сценарием: нет очереди старых подсказок, reveal не повторяет вопрос, брендовый splash задерживает onboarding, скрытие страницы/условия/host pause ставят запись на паузу. Завершение WAV не переключает экран.

- [Версия и API Howler](https://github.com/goldfire/howler.js/blob/v2.2.4/README.md).
- [MIT и package](https://github.com/goldfire/howler.js/blob/v2.2.4/package.json).
- [Issue1303: ограничения autoplay](https://github.com/goldfire/howler.js/issues/1303): библиотека не отменяет правила браузера.
- [Issue1725: не всегда приходит playerror](https://github.com/goldfire/howler.js/issues/1725): нельзя полагаться только на событие ошибки для разблокировки.
- [Chrome autoplay](https://developer.chrome.com/blog/autoplay): для первого запуска может требоваться взаимодействие.

Выбран HTML5 media backend Howler для коротких локальных WAV; это также исключает зависимость очереди озвучки от suspended AudioContext. Неактуальные callbacks отменяются при смене screen key. Секреты и provider voice ID не входят в manifest и bundle.

## Ограничения и проверка

Камера автоматически переключается через1,8с; её WAV необходимо проверить отдельно по длительности. Длинные интерактивные подсказки допускают прерывание новым ответом. Начальное приветствие до первого взаимодействия не гарантируется политикой autoplay. Тембр, ударения и художественная приёмка остаются у пользователя; HTTP200 сам по себе их не доказывает.
