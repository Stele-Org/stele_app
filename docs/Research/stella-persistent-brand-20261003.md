# Постоянный логотип Стеллы — 03.10.2026

Проблема: React key на RingActions включал screen.type. Смена этапа удаляла main вместе с логотипом; глобальная screen-arrive снова запускала opacity0 и translateY14px. RingScene при этом уже сохранялся.

Готовый механизм: reconciliation React19.3.0, MIT. [Официальное описание сохранения состояния и влияния key](https://react.dev/learn/preserving-and-resetting-state). Поведение подтверждено регрессионным тестом: до исправления постоянного header нет, после сохраняются ссылки на DOM. Дополнительная библиотека или собственный механизм переходов не нужны.

Решение: общий main остаётся на прежней позиции без изменяемого React key. Существующий RingActions.phaseKey сбрасывает только RingCue и состояние выбора. Один VK header находится в постоянном слое RingScene, вне анимации экранов. Локальные marks отключаются через showProductMark. Брендовый splash сохраняет намеренную анимацию.

Ограничения: сменяемое содержимое продолжает обновляться, это нормальный React render. Исправление предотвращает remount общей оболочки и VK логотипа, но не обещает отсутствие любых GPU задержек. MAX локальные marks в этой итерации не переносились. [Проверка](../../artifacts/reports/stella-persistent-brand-20261003.md).
