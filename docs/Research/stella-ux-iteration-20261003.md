# Стелла: визуальная итерация по Стела UX

03.10.2026. Пользователь выбрал STELLA-2 (знаки рядом) и явно сохранил текущие вопросы/рекомендации. Переносим визуал, не4-вопросный сценарий. Источник — [изученные22пары](stella-ux-screens-20261003.md).

Готовые материалы: SVG-карточки с исходными raster patterns, clip/mask/filter/градиентами. Выделяем нужные группы и транзитивные defs, убираем только белые path-подписи вне mask: надписи остаются живыми текстами действующих ответов. ИсходныеPNG в defs не перекодируются. Это подготовка предоставленных ассетов, не новый рендер/анимационный движок. Шрифты/логотипы — действующие пакеты брендов.

Механика остаётся готовой Motion13.5.0/framer-motion13.5.1(MIT) + LumiCells1007717(UNLICENSED, разрешение владельца), изученной с документацией/реальными issues в [исследовании переходов](stella-continuous-transitions-20261003.md) и [общей интеграции](../../artifacts/reports/stella-all-transitions-20261003.md). Новых библиотек/собственной анимации не вводим. Native изображения в button сохраняют текст/aria-label/hit-target текущего RingTag.

Целевая композиция: VK468×280,MAX465×280, радиус60; третьяMAX-цель по центру. Вопросы/CTA остаются доY1280, поэтому Назад при четырёх/трёх вариантах чуть выше, чем в некоторыхSVG. Фото близко к14, MAX-материал/иллюстрации20/8, CTA7, инструкцияVK16. Тексты/миссии/юридическая ссылка/QR не удаляются из-за отсутствия в части макетов. Реальный голос и камера этой итерацией не добавляются; состояния error4/17 не симулируют работающий ASR.

Картинки VK сопоставлены с действующими ответами по смыслу; это не перенос скрытых весов изSVG. Теги VK получили тёмную заливку и цветной контур по19; для центрированной третьей карточки MAX свободные области посадки расположены сверху. Авторский seeded/flight и согласованный уход ответа с последней группой сохранены. Фон остаётся текущим LumiCells.

Ограничения: SVG img с фильтрами/masks нуждается в пользовательской визуальной проверке, статичный экспорт не задаёт движение. Суммарно17SVG занимают27.23MB; исходные embeddedPNG сохранены, скорость первого декодирования/память не измерялись. Прежний native Image.decode preloader расширен на15 карточек, без блокировки старта. [Проверка реализации](../../artifacts/reports/stella-ux-iteration-20261003.md).
