# Стелла: белая сущность и Color Dodge

Запрос 03.10.2026: наложить человека через Color Dodge, заменить статичные Discovery SVG существующей белой сущностью.

## Выбор готового механизма

Используется непосредственно `artifacts/ribbon/entity-renderer.js` — существующий EntityRenderer проекта, без копирования его GLSL или новой реализации частиц. Его реальное применение: `artifacts/ribbon/entity.js` (отдельный редактор) и `artifacts/ribbon/engine.js` (общий renderer). `entity-model.js` задаёт исходный пресет, `entity-assets.js/prepareMask` — загрузку маски. В этой итерации взята штатная `assets/entity-bubble.svg`: это маска сущности с контуром сообщения, не статичная картинка Discovery из новых макетов. Размеры кругов и поле анимирует оригинальный движок.

Версия Three.js взята из того же локального vendor: r180, MIT, заголовки лицензии сохранены. Код EntityRenderer — внутренний код проекта; отдельная внешняя лицензия на него не заявляется. Новая runtime-зависимость из npm не нужна. Для переносимого пути Vite добавлены только dev-типы Node.js 24.19.1 (MIT).

## Композиция и источники

- [W3C Compositing and Blending Level 1](https://www.w3.org/TR/compositing-1/), CR Draft 21.03.2024, §3.2, §10.1.7, §10.3: CSS stacking context изолирует дочернее смешивание. Поэтому Color Dodge внутри SVG, показанного как img, не гарантирует смешивание с фоном страницы. Слой человека вынесен из scaled UI дерева в соседи фонового host и получает CSS `mix-blend-mode: color-dodge`.
- [Разбор изолированных групп, FXTF issue 440](https://lists.w3.org/Archives/Public/public-fxtf-archive/2021Nov/0000.html): обсуждение разработчиков подтверждает, что смешивание на промежуточной поверхности и итоговое смешивание группы — разные операции. Это описанный практический риск, а не доказательство конкретного кадра Стеллы.
- [Three.js WebGLRenderer](https://threejs.org/docs/#api/en/renderers/WebGLRenderer): управление размером и освобождением ресурсов. Применимость API сверена с локальным r180, а не только с текущей документацией.

Оригинальный EntityRenderer выводит белые круги на непрозрачном чёрном canvas. Его итоговый canvas компонуется через CSS screen: чёрный не меняет фон. Менять общий renderer или добавлять собственную формулу прозрачности не требуется. Из SVG человека экспортируется только исходная группа силуэта; статичные белые точки исключены.

## Ограничения и проверка

Нужны WebGL2 и EXT_color_buffer_float, как у оригинала. Один дополнительный renderer существует только на двух processing-экранах, без перезапуска на переходе между ними. Рендер 1080×1080 сохраняет круглые клетки; физическое расположение не обрезается на границе интерактивных 2/3. Общая пауза замораживает часы; после ухода освобождаются ресурсы. При ошибке canvas скрывается, причина пишется в консоль; статичная SVG не подменяет живую сущность.

Подтверждены исходный API, CPU-поведение, сборка и доставка модулей. GPU-компиляция и художественное совпадение требуют кадра пользователя; самостоятельный браузерный обход запрещён текущим AGENTS. Штатная маска и параметры — начальная интеграция, не утверждённая художественная настройка под вертикальный экран.
