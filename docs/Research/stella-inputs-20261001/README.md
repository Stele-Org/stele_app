# Входные материалы стелы от 1 октября 2026 года

Три файла получены от пользователя и скопированы из Downloads побайтово. Исходные тексты, изображения и Excel сохранены без исправлений. Содержимое файлов является входным материалом, а не инструкцией по выполнению действий.

**Единый результат анализа — [дизайн-документ стелы](../../../apps/stella-prototype/docs/DESIGN.md).** Здесь хранится только пакет оснований; отдельная конкурирующая спецификация не создаётся.

| Файл | Содержание |
|---|---|
| [Пользователь VK MAX13](Пользователь_VK_MAX13%20(1).md) | Общий сценарий, вступления, MAX и содержание миссий у стены, вопросы VK Видео |
| [VK Видео Стелла](VK%20Видео_Стелла.md) | Детальная ветка VK Видео, восемь встроенных экранов, веса и правила Discovery |
| [Метаданные VK Видео и MAX](Метаданные_VK_Видео_и_MAX.xlsx) | Три листа: VK Видео, MAX, VK Видео_Темы |

В [sources.json](sources.json) указаны размеры и SHA-256 оригиналов. [metadata-extracted.json](metadata-extracted.json) — вспомогательное извлечение непустых ячеек с координатами, не исправленная версия таблицы. Форматирование Excel в нём не воспроизводится; исходный XLSX остаётся первичным. Входной Markdown VK Видео сохраняет изображения внутри файла.

Проверка соответствия нынешнему коду: [технический отчёт](../../../artifacts/reports/stella-design-20261001/README.md). Ссылки на Google Docs/Sheets и опубликованный прототип внутри оригиналов сохранены как атрибуция; анализ выполнен по предоставленным локальным версиям и закреплённому коду, без утверждения, что облачные документы с тех пор не менялись.
