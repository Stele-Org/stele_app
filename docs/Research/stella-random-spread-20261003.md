# Стелла: случайная раскладка на готовом движке LumiCells

03.10.2026. Задача — убрать колонку тегов, сохранить ответ и короткую остановку. [Референс пользователя](../../artifacts/reports/stella-persistent-answer-reference-20261003.png).

Выбрано изменение параметров уже перенесённого LumiCells demo/scene: `SceneItem.fx/fy` задают точки посадки, `Choreographer` сам вычисляет направления входа и выхода, `flight.ts` содержит готовый `seeded()` и использует его для разброса float. Источник — [LumiCells](https://github.com/supsad/lumicells), закреплённая ревизия `1007717d72cfd9d768d4b9a3f7fc80a126e49c51`, пакет 0.1.0, private/UNLICENSED, применение кода коллеги разрешено указанием проекта. [Аудит исходника, интеграции и ограничений WAAPI](stella-lumicells-native-motion-20261002.md). Это подтверждённое чтением кода поведение демо; публичных подтверждений промышленной эксплуатации случайной раскладки нет.

Для текущей задачи готовый механизм — авторские `seeded`, `flyIn`, `startFloat`, `flyOut` и Choreographer. Новая физика или решатель столкновений не нужны: четыре области посадки назначаются версткой с учётом постоянной карточки, внутри них авторский генератор выбирает координаты. Случайные смещение порядка и его направление меняют соответствие тегов областям. Новый seed создаётся один раз на ответ, группа получает свой seed; пауза и React rerender его не меняют.

Дополнительно рассмотрены [d3-random](https://github.com/d3/d3-random) (готовые распределения, ISC) и [Math.random — MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random). Они не реализуют авторский полёт или размещение вокруг карточки; добавлять d3 только ради случайного числа нет оснований. Math.random используется только для начального seed, воспроизводимый разброс выполняет готовая функция LumiCells. Версия d3 не выбиралась, зависимость не устанавливается.

Ограничения: это ограниченная случайность внутри подготовленных свободных областей, не автоматическая упаковка произвольного количества объектов. Группа остаётся максимум четыре тега, ширина ограничена 440px. Входящие/исходящие траектории могут пересекаться и проходить за карточкой; свободное размещение проверяется для остановки. Тест координат не доказывает читаемость реального шрифта, форму тени или восприятие движения. Нужен пользовательский кадр; самостоятельный браузерный обход запрещён рабочим процессом.
