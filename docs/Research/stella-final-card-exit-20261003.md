# Стелла: выбранная карточка уходит с последними тегами

03.10.2026. Новый отзыв отменяет сохранение карточки между вопросами: она остаётся во время групп тегов, уходит при начале последнего вылета, затем входят четыре новых варианта.

Новый движок не нужен. Motion13.5.0 / framer-motion13.5.1, MIT, уже выполняет exit через AnimatePresence/usePresence/useAnimate. [Документация](https://motion.dev/docs/react-animate-presence) подтверждает отслеживание удаления и смены ключей; sync позволяет нескольким карточкам входить/уходить, wait поддерживает только одного ребёнка. Используем имеющийся sync и смысловые ключи question.id/option.id. Ограничения и реальные регрессии3803/3084 разобраны в [основном исследовании](stella-continuous-transitions-20261003.md).

Исходный LumiCells commit1007717, UNLICENSED/разрешение владельца, уже сообщает onFlight start/end и data-phase. Адаптер AnswerFlight может однократно уведомить родителя о leaving/start последней группы, не рассчитывая таймер поверх анимации. Следующий вопрос по-прежнему запускается после реального завершения Choreographer. React19.3 useEffectEvent позволяет обработчику эффекта читать текущий callback без перезапуска полёта: [официальный контракт](https://react.dev/reference/react/useEffectEvent). Срабатывание на каждый тег фильтруется локальным once-флагом; промежуточные группы не убирают ответ.

Границы: совместный старт ухода, а не покадровое совпадение разных easing. Motion управляет карточкой, исходный LumiCells — тегами; spring/float/hold остаются прежними. Охват — первая цепочка VK Видео, визуальная оценка пользователем. [Проверка](../../artifacts/reports/stella-final-card-exit-20261003.md).
