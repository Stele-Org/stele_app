# Стелла: мягкая смена карточек и движение в покое

03.10.2026. Пользователь подтвердил улучшение первой непрерывной цепочки, но отклонил быстрый темп, неподвижное исчезновение и резкую смену сохранённого ответа. Это продолжение той же итерации вопросов1→2, не новый дизайн.

По коду предыдущая версия использует только opacity240/180ms; QuestionPanel с ключом номера вопроса удаляет и выбранную карточку. Отдельной постоянной анимации у кнопок нет. Зависание как функциональная ошибка пока не воспроизведено; визуальный симптом пользователя принят, а пауза неподвижного fade объяснима текущей реализацией.

Готовые механизмы: установленный Motion13.5.0 / framer-motion13.5.1, MIT — AnimatePresence для удаления/смены контента, useAnimate и физическая spring со stiffness/damping/mass для появления/ухода. [Официальные параметры](https://motion.dev/docs/animate): физическая spring учитывает скорость, duration/bounce — другой вариант без переноса скорости. Не выдаём авторский float за физическую симуляцию. Регрессии presence и их применимость изучены в [предыдущем исследовании](stella-continuous-transitions-20261003.md), включая issues3803/3084; не используем wait/popLayout.

Движение в покое берётся из готового `startFloat` LumiCells0.1.0, commit1007717, private/UNLICENSED, использование разрешено проектом. Он задаёт независимые фазы и мягкое периодическое смещение. Функция не переписывается; отдельный внутренний DOM-слой исключает конфликт с transform/opacity Motion. WAAPI playbackRate=.75 замедляет существующий float. При смене содержимого выбранной карточки тот же слой и его анимация продолжают жить. При pause/reduced motion/unmount применяются существующие WAAPI controls.

Постоянная карточка определяется физическим слотом, а текст/иллюстрация — смысловым option.id. AnimatePresence внутри кнопки плавно сменяет её содержимое. Сценарные id не подменяются индексом слота. RingActions получает отдельный token вопроса для обновления gate без уничтожения детей; Back создаёт новый token даже для прежнего вопроса. Это адаптация React lifecycle, не новая библиотека анимации.

Стартовые параметры для оценки: spring90/18/mass1.1, fade вход550ms/выход440ms; контент420ms/280ms, заголовок620ms/280ms. Небольшой stagger по карточкам. Только embedded-полёт первого ответа растягивается в1.25раза; hold350ms сохраняется. Это художественные настройки для проверки пользователем, не измеренный оптимум. Сквозное сохранение скорости между float и spring не заявляется: они независимы и суммируются на разных DOM-слоях.

[Отчёт интеграции](../../artifacts/reports/stella-soft-inertia-20261003.md). Браузерный просмотр агентом не выполняется; технические проверки не заменяют оценку движения на экране.
