# Рабочие ресурсы

- `fonts/` – локальные файлы Montserrat и VK Sans, подключённые в CSS.
- `images/backgrounds/` – полноэкранные фоны 1080 × 1920.
- `images/home/` – цельные кнопки и графика стартового экрана.
- `images/controls/` – кнопка «назад» и фон вариантов MAX.
- `images/brands/` – продуктовые логотипы.
- `images/results/` – графика финальных экранов.

Здесь хранятся только файлы, которые импортируются приложением. Неизменяемые пользовательские экспорты остаются в корневой папке `экспорты/`.
