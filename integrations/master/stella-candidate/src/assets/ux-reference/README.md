# Материалы Стела UX

17 SVG выделены из предоставленных экранов в `artifacts/DESIGN/UI/stela/Стела UX/`: 15 карточек, указатель касания и материал CTA MAX. Исходники клиента не изменены. `provenance.json` связывает каждый ресурс с исходным SVG, SHA и областью кадрирования.

Воспроизведение: `python artifacts/stella-prototype/scripts/extract-ux-cards.py` из корня проекта. Скрипт сохраняет исходные embedded PNG, нужные defs, clip/mask/filter/градиенты; удаляет белые контурные подписи вне масок. Тексты ответов рисует приложение из текущего сценария. SVG остаются крупными (суммарно 27.23 MB), без перекодирования клиентской графики.

Назначение иллюстраций — `src/components/ux-artwork.ts`; это визуальное сопоставление, не изменение весов рекомендаций. Motion/LumiCells управляют прежними живыми кнопками. Право использования следует из предоставления материалов пользователем для проекта; отдельная публичная лицензия на клиентские изображения не заявляется.
