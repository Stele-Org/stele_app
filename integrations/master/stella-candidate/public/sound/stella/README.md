# Звуковые эффекты Стеллы

Пользовательский набор `stella sfx 1st pass`, переданный 04.10.2026: 12 WAV скопированы без изменения PCM, темпа, громкости или формата. Демонстрационный MP4 не включён. Состав, исходные SHA256 и проверка копий — `sound-source-manifest.json`; стабильные роли для приложения — `manifest.json`.

| Роль | WAV | Привязка |
|---|---|---|
| `ambienceMain` | `stella_ambience_loop_main.wav` | Основной ambience вне фактического сканирования |
| `ambienceScan` | `stella_ambience_loop_scan.wav` | Ambience только во время фактического сканирования в ветке фото |
| `buttonClick` | `stella_button_click.wav` | Принятое действие общего `RingActions`; отклонённые/заблокированные действия не звучат |
| `scanStart` | `stella_scan_start_1.wav`, `stella_scan_start_2.wav` | Начало фактического сканирования; варианты 1 и 2 последовательно по циклам |
| `scanEnd` | `stella_scan_end_1.wav`, `stella_scan_end_2.wav` | Завершение фактического сканирования; варианты 1 и 2 последовательно по циклам |
| `transitions` | `stella_transition_1.wav` … `stella_transition_5.wav` | Ответы при входе в reveal: последовательно 1 → 2 → 3 → 4 → 5 → 1 |

На главной счётчик переходов сбрасывается: новый проход начинает с `stella_transition_1.wav`. Порядок переходов общий для принятых ответов и не зависит от способа ввода. Scan ambience и scan start/end не должны срабатывать в проходе без фактического сканирования, включая пропуск фото.

Начало и завершение сканирования используют парные варианты одного цикла: start 1 / end 1, затем start 2 / end 2, затем снова 1. Триггеры сканирования относятся к переходам состояния сценария и не подменяют методы камеры или генерации. Уровни громкости и обработку паузы/отключения определяет общий runtime-плеер. Реплики Василисы остаются отдельным голосовым набором.
