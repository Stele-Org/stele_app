# Единая Стелла — 0501.2-стенд

Основной исходник: `stella-candidate/`. Один build объединяет `0410upd`/`1dfa653`, стендовые обновления `0501-стенд`/`8cab859` и карточки из `bebca47`. Старый standalone сохранён для происхождения ассетов и принятых изменений; запускать его для проверки нового кандидата не нужно.

## Что перенесено

- Исходный попкорн с маской тёмного телевизора; пользовательская пара и «Чтобы был азарт и драйв». Новые изображения не генерировались.
- Реальный DOCX-согласие: 21 абзац, семь пронумерованных разделов и редакция; локальная прокручиваемая панель и условия камеры показывают один JSON.
- Фото только для hero. Локальный сценарий направляет остальные ответы сразу к нейтральным частицам. Master использует его объявленный `skip` через fenced `photo_choice`, либо штатный `photo_skip` на камере; неизвестные будущие ответы не переинтерпретируются.
- Убраны текст активации и лишний текст photo-reveal. Живой hero preview и общий startup camera stream сохранены.
- Рассеивание/нейтральные частицы семь активных секунд. Ранний server final удерживается до renderer completion; после смены серверной фазы старый ACK не отправляется. Cancel, чужая сессия, перезапуск MASTER удаляют удержание. Ошибка renderer не подтверждает неотработавшую анимацию и не удерживает уже подтверждённый сервером финал.
- «Смотри в камеру над экраном»; короткий финал «к левой панели», короткое тире, без точки; крупный QR и принятый фон. В master QR по-прежнему кодирует настоящий принятый package/resultPath и доверенный result origin.
- Финал исчезает через 20 видимых активных секунд. В master это только смена представления: release, очередь и допуск следующего посетителя остаются у сервера.
- Переносы онбординга и MAX ID. Стендовый `voiceEnabled=false` сохранён: голосовой ввод не включается ради подсказки.
- Новая механика обложка → фрагменты/коды → световые нити → реальные теги → общий поток сохранена в VK и MAX. Метаданные, scoring и серверные команды не заменены локальными догадками.

## Звук

Новые 12 SFX, последовательные transitions и парные scan start/end перенесены. Готовая реплика Discovery длится 6,77 секунды с паузой 400 мс. Screen3 использует готовую общую реплику вопроса без старого ответа «Чтобы смеяться». Фото/камера/финал имеют утверждённый текст, но соответствующие новые WAV отсутствуют, как и в `0410upd`; старые записи не воспроизводятся. Синтез не выполнялся.

AUDIO-02 Howler observer, buses, clocks, старые IDs и muted Electron сохранены. Девять дополнительных cue IDs и изменённые файлы существующих IDs надо установить на центральном MASTER вместе с UI: [`central-catalogue.candidate.json`](stella-candidate/public/audio/vk-production-v1/central-catalogue.candidate.json), [`README звука`](stella-candidate/public/audio/vk-production-v1/README.md). Каталог проверен по фактическим WAV; это карта интеграции, а не выдуманная схема отсутствующего backend. Копирование одного dist без обновления центрального каталога не обновит слышимый стендовый звук.

## Запуск и сборка

Из корня репозитория, Node.js >=24:

```sh
npm --prefix integrations/master/stella-candidate ci --ignore-scripts
npm --prefix integrations/master/stella-candidate run dev
```

Локальный просмотр: `http://127.0.0.1:5218/stella/`. Серверный режим: `/stella/?master=1`, с совместимым backend через loopback `STELLA_MASTER_TARGET`. Backend, БД, секреты и физический аудиовыход здесь не экспортированы. Локальный режим показывает UI, но не выдаёт себя за подтверждённый master результат.

```sh
npm --prefix integrations/master/stella-candidate run typecheck
npm --prefix integrations/master/stella-candidate test
npm --prefix integrations/master/stella-candidate run lint
npm --prefix integrations/master/stella-candidate run build
```

Выход: `stella-candidate/dist`. В переносимом ZIP `stella/` содержит этот dist, `candidate-manifest.json` — SHA всех файлов, `UNIFIED_BUILD.md` — этот документ. Сохранённый pin установленной сборки остаётся историческим; сайт, F и стенд автоматически не обновляются. Визуальную приёмку и проверку физической камеры/звука выполняет пользователь.
