# PhotoStorage

Сюда dev-сервер Стеллы складывает фотографии, которые посетитель одобрил в локальном сценарии кнопкой «Продолжить». Отсюда их может забирать другой сервер или программа обработки.

Фотографии — персональные данные. В git попадает только этот файл: всё остальное содержимое папки игнорируется (`.gitignore`). Папка не очищается сама, удаляйте файлы вручную.

## Что лежит в папке

Одна фотография — два файла с одним именем:

```
20261006T194512Z_4f0c2c1e-6a51-4b8e-9d3f-2b7a9c1e5d10.jpg    снимок, JPEG до 1 МБ, длинная сторона до 960 px
20261006T194512Z_4f0c2c1e-6a51-4b8e-9d3f-2b7a9c1e5d10.json   описание
```

Имя — время сохранения по UTC и номер снимка. Описание:

```json
{
  "captureId": "4f0c2c1e-6a51-4b8e-9d3f-2b7a9c1e5d10",
  "file": "20261006T194512Z_4f0c2c1e-6a51-4b8e-9d3f-2b7a9c1e5d10.jpg",
  "storedAt": "2026-10-06T19:45:12.345Z",
  "bytes": 84213,
  "sha256": "…",
  "upright": true
}
```

`upright: true` — камера стояла прямо (`?camera=any`); `false` — кадр стендовой BRIO, уже повёрнутый в вертикальное положение. `sha256` — контрольная сумма файла снимка.

## Как узнать, что появилась новая фотография

Следите за появлением файлов `*.json`. Описание записывается последним, после снимка, и оба файла появляются под своим именем уже целиком: пока идёт запись, файл называется `*.part`. Если `.json` есть, снимок рядом с ним готов к чтению. Файлы `*.part` читать не нужно.

Повторная отправка того же снимка (тот же `captureId`) второй пары файлов не создаёт.

## Что сохраняется, а что нет

- Сохраняется только фото, с которым посетитель нажал «Продолжить».
- Фото, после которого нажали «Повторить», не сохраняется.
- Работает только с dev-сервером (`.\scripts\stella.ps1 dev`). В собранном приложении и на стенде этой папкой никто не пользуется: там снимок уходит в MASTER.

## Внешний доступ

Это обычная папка с файлами, поэтому доступ к ней даётся средствами системы или сети:

- открыть папку как сетевой ресурс Windows только на чтение и дать доступ серверу обработки;
- синхронизировать папку на другой компьютер;
- перенести хранилище в уже общую папку: задайте переменную окружения `STELLA_PHOTO_STORAGE` с полным путём до запуска dev-сервера.

Сам dev-сервер слушает только `127.0.0.1` и наружу эту папку не раздаёт.
