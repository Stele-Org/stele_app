# Итоги теста VK Видео: все сочетания ответов — 08.10.2026

Здесь лежат файлы итога, которые локальный сценарий Стеллы записал при проходе в настоящем Chrome: 96 файлов по всем сочетаниям ответов и 4 файла из проходов с возвратом назад. Формат файла описан в [ResultStorage/README.md](../../../ResultStorage/README.md).

Сочетания: 48 без ответа «Хочу стать героем VK Видео» и 16 сочетаний героя в трёх вариантах фото — снимок одобрен, снимка нет, «Пропустить».

## Как получены

- Ветка `codex/result-json-20261007`, коммит `385c215`. Chrome 154 без окна, отдельный профиль; dev-сервер на порту 5219 с временными папками вместо `ResultStorage` и `PhotoStorage`.
- Каждый проход начинался с загрузки страницы и шёл настоящими нажатиями мыши: логотип VK Видео, «начать», три ответа, для героя — «Начать» или «Пропустить», кнопка камеры и «Продолжить» на проверке фото. Всего 632 нажатий, все попали в свои кнопки.
- Камеру заменял поддельный видеопоток Chrome (зелёное поле со счётчиком) со ссылкой `?camera=any`; настоящих лиц в прогоне нет. Вариант «снимка нет» шёл без этого параметра: строгий поиск BRIO камеру не находит, на проверке фото чёрный квадрат.
- Файлы скопированы без изменений и переименованы по номерам ответов из таблицы клиента. Идентификатор сессии и время внутри — настоящие, из прогона.

Имя файла: `1.x-2.x-3.x.json`. У героя добавлен вариант фото: `_photo` — снимок одобрен, `_no-photo` — согласие без снимка, `_skip` — «Пропустить».

Скрипты прогона лежат в [tools](tools): `drive.mjs` управляет Chrome через его отладочный порт и проходит сценарий, `verify.py` сверяет полученные файлы. Dev-сервер и Chrome для них запускаются отдельно: сервер с переменными `STELLA_RESULT_STORAGE` и `STELLA_PHOTO_STORAGE`, Chrome с отладочным портом и поддельной камерой.

## Результат проверки

Получено 100 файлов из 100, повторных попыток 0, ошибок на странице нет. Каждый файл сверен отдельным скриптом, который не использует код приложения: 0 расхождений.

Что сверялось в каждом файле:

- ответы и теги — с ответами, стоявшими в конце прохода, и таблицей клиента «Метаданные VK Видео и MAX»;
- страница отправила итог ровно один раз, и на сессию есть ровно один файл;
- очки тематик — с весами из той же таблицы; порядок тематик — по убыванию очков;
- обложки — всего шесть; по две на три лучшие тематики и пустой `aiCover`, а у героя с одобренным фото по две на две лучшие тематики и по одной ИИ-обложке на два лучших жанра;
- у героя без фото (`_no-photo`, `_skip`) ИИ-обложек нет: те же шесть обложек по трём тематикам;
- очки жанров и соответствие жанра тематике — с таблицами от 07.10.2026;
- обложка никогда не назначена тематике или жанру без очков;
- фото — статус, а для одобренного снимка номер совпадает со снимком, сохранённым в хранилище фото;
- файл на диске совпадает с тем, что отправила страница; порядок полей в файле.

Тематики и жанры с равными очками разыгрываются случайно, поэтому файл показывает один из возможных исходов для своего сочетания: при повторном проходе порядок равных может быть другим.
