# Прототипы из сессии Claude Design «Анализ дизайна Стелы» — 05.10.2026

HTML-прототипы анимаций Стеллы (1080×1920), собранные в Claude Design. Это исходный референс движения и таймингов. Сами сцены перенесены в приложение 05.10.2026 и запускаются вместе с ним, см. [отчёт](../../reports/claude-design-scenes-20261005.md). Прототип не является кодом приложения: прототип нарисован по пяти скриншотам, исходников стенда у дизайн-инструмента не было. Разбор сессии, итоговые решения и тайминги: [docs/Research/stella-claude-design-session-20261005.md](../../../docs/Research/stella-claude-design-session-20261005.md).

## Файлы

| Файл | Что это |
| --- | --- |
| `Stela.standalone.html` | Актуальная версия прототипа одним файлом: все экраны, все варианты анимаций, панели переключения, запись MP4. Работает без интернета, открывается двойным щелчком. |
| `dc/Stela.dc.html` | Тот же прототип в читаемом виде: разметка и класс `Component` с логикой. Получен распаковкой `Stela.standalone.html` скриптом `scripts/import-design-bundle.mjs`. |
| `dc/Stela D2 - gradient.dc.html` | Более ранний экспорт: вариант тегов «D2 код → шарики», рамка тега градиентная. Без выбора разрешения записи. |
| `dc/Stela D2 - solid.dc.html` | То же, тег с заливкой. От градиентной версии отличается только значением `tagLook` по умолчанию. |
| `dc/support.js` | Среда выполнения Claude Design (`dc-runtime`), сгенерированный файл, не редактировать. |
| `dc/assets/`, `dc/fonts/` | Картинки карточек и логотипов, VK Sans Display, JetBrains Mono. |
| `provenance.json` | Источники файлов и SHA256. |

Файлы `*.dc.html` при открытии загружают React и Babel с unpkg.com, поэтому им нужен интернет. `Stela.standalone.html` содержит всё внутри.

## Как открыть

Сцены в приложении: `.\scripts\stella.ps1 dev`, затем `/stella/?reveal=series` и `/stella/?discovery=generation`.

Исходные страницы для сравнения, из корня проекта:

```powershell
.\scripts\stella.ps1 design
```

Откроется список страниц на http://127.0.0.1:5219/. Порт можно задать вторым аргументом.

В прототипе внизу экрана есть панель: выбор экрана, варианта появления тегов, вида тега, варианта Discovery, разрешения записи. Принятые в сессии варианты: теги — «D2 код → шарики», Discovery — «D1 пульс + нейросеть».

## Ограничения

- Картинки карточек и объёмные логотипы вырезаны из скриншотов, качество низкое. В приложении использовать оригиналы из `artifacts/DESIGN/BRANDS` и `src/assets`.
- Тексты и координаты экранов воссозданы по скриншотам и могут расходиться с приложением. Источник текстов — `integrations/master/stella-candidate/src/content`.
- Сценария MAX в прототипе нет: логотип MAX только подсвечивается.
- Голос в прототипе отключён по запросу в сессии.
- Запись MP4 идёт в браузере в реальном времени. По AGENTS.md запись видео согласуется отдельно.
