# Стелла: комплект постеров для Polza

Переносимый комплект для интегратора мастера F: **20 фонов без главного героя (10 мужских + 10 женских), 10 жанровых рецептов с ветками male/female** и Python-адаптер Polza Seedream 5 Lite. Вход №1 — фотография посетителя, №2 — выбранный фон. Полный промпт собирается из `prefix + common + male/female`; каждая из 20 комбинаций укладывается в 2996 символов.

Это компонент для интеграции. Очередь, DBOS, разрешение платного запроса, фотографии, состояние задания, хранение и публикация результата остаются у мастера. Готовый план переноса — [MASTER_INTEGRATION.md](docs/MASTER_INTEGRATION.md); фактические ограничения текущего F указаны там отдельно.

## Состав

- `assets/clean-plates/` и `assets/manifest.json` — 20 PNG, размеры и SHA-256.
- `prompts/recipes.json` — машинные рецепты; прочие файлы `prompts/` — читаемое описание.
- `stella_polza/` — `Catalog.prepare`, `PolzaClient.submit_once`, `get_status`, `download_result`.
- `examples/master_boundary.py` — раздельные вызовы и граница ответственности мастера; запуск файла ничего не отправляет.
- `preview/index.html` — локальный просмотр; `evidence/` — принятый результат и параметры одной проверки.
- `docs/Research/` — [исследование](docs/Research/README.md); [OPERATIONS.md](docs/OPERATIONS.md) — эксплуатация, ошибки и политика unknown.
- `tests/`, `licenses/`, `NOTICE.md`, `provenance/` — офлайн-проверки, зависимости и происхождение материалов.

**Проверен и принят пользователем один платный пилот: мужской боевик. Остальные 19 вариантов подготовлены, но платную проверку в Polza не проходили.** Пилот: Basic, 16:9, 2848×1600, 73,36 с, 4 ₽. Это измерение одного запроса, не гарантированные срок и цена. Генеративные фоны не обещают попиксельного сохранения оригиналов; итог всех жанров требует визуальной приёмки.

## Установка и проверка

Требуется Python **3.10+** (проверен Python3.14). В PowerShell перейдите в папку комплекта `artifacts/stella-polza-kit`. Папку можно перенести целиком: рабочие пути внутри неё относительные.

Точная версия файлов закреплена в `KIT_MANIFEST.json`. [Результаты проверки](docs/VERIFICATION.md). После переноса запустите `kit.py verify`, чтобы проверить SHA каждого файла поставки.

```powershell
.\setup.ps1 -Python "C:\Path\To\Python\python.exe"
.\.venv\Scripts\python.exe kit.py verify
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
.\.venv\Scripts\python.exe kit.py catalog
Start-Process .\preview\index.html
```

`setup.ps1` создаёт `.venv` и скачивает зафиксированные зависимости с PyPI; это требует сети, но не вызывает AI. **После установки `verify`, тесты, каталог и preview работают офлайн**, без ключа и платных запросов. Тесты используют HTTPX MockTransport и синтетическое изображение. Для полностью изолированной установки интегратор должен заранее предоставить совместимые wheels из `requirements.lock.txt`; wheels в комплект не включены.

Подготовить запрос без сети, используя фотографию вне комплекта:

```powershell
.\.venv\Scripts\python.exe kit.py prepare --photo "C:\MasterData\private\visitor.png" --genre 01_BOEVIK --variant male
```

Команда выводит промпт и контрольные суммы, не фотографию и не base64. Не направляйте эти данные в публичные журналы. `config.example.json` — справочный пример для интегратора: библиотека и CLI **не читают его автоматически**. Изменение `enabled` в этом файле ничего не запускает.

## Платный вызов — только через мастер

Ключ внедряется мастером в `PolzaClient`; входная фотография, секреты и runtime-результаты должны храниться вне комплекта. `kit.py` не имеет команды генерации. Пример не содержит ключей, автоматического POST, цикла опроса, retry или собственной БД.

До `submit_once` мастер должен явно разрешить оплату и атомарно сохранить reservation/fence для конкретных job/attempt и неизменяемых входов. `user` — лишь корреляция; один вызов Python не обеспечивает exactly once при сбоях. При `SubmitUnknown` повторный POST запрещён: мастер сверяет исход, а при известном provider ID продолжает `get_status` того же задания. Расписание GET и сроки задаёт мастер.

`completed` у провайдера ещё не означает `ready` у мастера. Сначала `download_result` проверяет и сохраняет изображение в существующий каталог мастера (новое имя, без перезаписи), затем мастер проверяет актуальность photoRevision/job/attempt и фиксирует свой assetRef. CDN-ссылка провайдера не является постоянной ссылкой посетителя. Текущий fixture API мастера не объявляется совместимым с production PNG — необходимые изменения описаны в [плане интеграции](docs/MASTER_INTEGRATION.md).
