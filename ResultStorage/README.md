# ResultStorage

Сюда dev-сервер Стеллы складывает итоги теста VK Видео: один файл JSON на одного посетителя. В файле тематики с количеством роликов по каждой, для героя — жанры обложек с количеством видео, теги, ответы, выбор Discovery и сведения о фото — то, что должно отразиться на стене VK Видео и на странице по QR-коду.

В git попадает только этот файл: всё остальное содержимое папки игнорируется (`.gitignore`). Папка не очищается сама, удаляйте файлы вручную.

## Когда появляется файл

Файл записывается в момент, когда посетитель сделал последний выбор, до анимации Discovery и финального экрана:

| Третий ответ | Что считается последним выбором |
|---|---|
| Любой, кроме «Хочу стать героем VK Видео» | Сам третий ответ |
| «Хочу стать героем VK Видео», затем «Пропустить» | «Пропустить» |
| «Хочу стать героем VK Видео», затем «Начать» | «Продолжить» на экране проверки фото |

Если посетитель ушёл раньше последнего выбора, файла не будет. На одну сессию пишется один файл; повторная отправка той же сессии второй файл не создаёт и первый не меняет.

Имя файла — время записи по UTC и идентификатор сессии:

```
20261007T101500Z_4f0c2c1e-6a51-4b8e-9d3f-2b7a9c1e5d10.json
```

Имена сортируются по времени: самый новый итог — последний по алфавиту. Пока идёт запись, файл называется `*.part`; под своим именем он появляется уже целиком. Файлы `*.part` читать не нужно. Кодировка UTF-8.

## Формат

Порядок в файле: сначала тематики с количеством роликов и жанры обложек, затем теги, затем ответы, в конце служебные сведения. Пример — ответы «Новый сериал, который все обсуждают», «Драйвовый», «Что-то похожее на то, что я уже люблю»:

## Поля

- `themes` — все восемь тематик от лучшей к худшей. У каждой: количество роликов (`videos`), очки (`score`), место (`rank`) и признак вхождения в первую тройку (`selected`).
- `genres` — жанры обложек с образом посетителя. Заполнено только при третьем ответе «Хочу стать героем VK Видео», иначе пустой список; см. раздел «Герой: жанры обложек».
- `tags` — все теги ответов подряд, каждый один раз. Это полный набор тегов посетителя.
- `answers` — ответы по порядку: три вопроса, а для героя четвёртым идёт шаг фото (`questionId: "photo"`, ответ `accept` или `skip`). У каждого ответа свои теги.
- `videos` — сколько роликов всего: `themes` — сумма по тематикам, `popular` — ролики из всего каталога по популярности, вне тематик, `genres` — видео с обложками посетителя, сумма по жанрам, `total` — сумма трёх.
- `selectedThemes` — первая тройка тематик, то же, что `selected: true`.
- `selectedGenres` — первая тройка жанров героя; у остальных ответов пустой список.
- `discovery` — третий ответ, правило подборки для него из таблицы клиента и тематики, которым это правило добавило по ролику (`extraThemes`).
- `photo` — что с фото посетителя, см. ниже.
- `schemaVersion`, `type`, `product` — версия и вид документа. При несовместимом изменении формата версия вырастет.
- `sessionId` — идентификатор сессии посетителя; тот же, что в имени файла.
- `createdAt` — время последнего выбора, UTC.

## Сколько роликов по тематикам

Основа: по одному ролику на каждую из трёх выбранных тематик. Дальше количество меняет третий ответ, по таблице клиента «Сюрприз Discovery»:

| № | Третий ответ | Правило клиента | Что меняется | Всего роликов |
|---|---|---|---|---|
| 3.1 | Что-то похожее на то, что я уже люблю | По одному видео из Топ 2 тематик для пользователя | +1 ролик первой и второй тематике: 2, 2, 1 | 5 |
| 3.2 | Новое, но по теме моих интересов | Дополнительное видео из тематики 3 или 4 | +1 ролик четвёртой тематике, если у неё есть очки (1, 1, 1, 1), иначе третьей (1, 1, 2) | 4 |
| 3.3 | Хочу стать героем VK Видео | Пул обложек с образом пользователя | Тематики без изменений (1, 1, 1), плюс три видео с обложками по жанрам: `videos.genres = 3` | 6 |
| 3.4 | То, чем прямо сейчас увлечены все | Самое популярное видео за последние 7 дней | Тематики без изменений (1, 1, 1), плюс один ролик из всего каталога: `videos.popular = 1` | 4 |

Два места здесь — решения Стеллы, а не таблицы клиента; их стоит подтвердить:

- **Основа «по одному ролику на тематику».** В документах клиента есть только правила сюрприза, базового количества нет.
- **«Тематика 3 или 4» в правиле 3.2.** Четвёртая тематика берётся, только если ответы дали ей очки. Так бывает, когда очки легли 2, 2, 1, 1: четвёртая — тематика с одним очком, не попавшая в тройку по жребию. Когда очки есть только у трёх тематик, четвёртая случайна и посетителем не выбрана, поэтому ролик добавляется третьей.

Самый популярный ролик правила 3.4 относится к тематике, которую знает только каталог, поэтому он считается отдельно от тематик. Ролик никогда не назначается тематике без очков.

## Герой: жанры обложек

Когда третий ответ — «Хочу стать героем VK Видео», в `genres` стоят все десять жанров обложек от лучшего к худшему. Пример для ответов «Новый сериал, который все обсуждают» и «Драйвовый»:

```json
"genres": [
  { "genre": "FANTASY", "videos": 1, "score": 2, "rank": 1, "selected": true, "title": "Фэнтези", "recipeId": "10_FANTASY", "theme": "Кино" },
  { "genre": "ADVENTURE", "videos": 1, "score": 2, "rank": 2, "selected": true, "title": "Приключения", "recipeId": "08_ADVENTURE", "theme": "Кино" },
  { "genre": "BOEVIK", "videos": 1, "score": 2, "rank": 3, "selected": true, "title": "Боевик", "recipeId": "01_BOEVIK", "theme": "Игры и авто" },
  { "genre": "HORROR", "videos": 0, "score": 1, "rank": 4, "selected": false, "title": "Хоррор", "recipeId": "09_HORROR", "theme": "Спорт" },
  { "genre": "DRAMA", "videos": 0, "score": 0, "rank": 5, "selected": false, "title": "Драма", "recipeId": "03_DRAMA", "theme": "Спорт" }
],
"videos": { "themes": 3, "popular": 0, "genres": 3, "total": 6 },
"selectedGenres": ["FANTASY", "ADVENTURE", "BOEVIK"]
```

В настоящем файле в списке все десять жанров; здесь показаны первые пять.

У жанра: количество видео с такой обложкой (`videos`), очки (`score`), место (`rank`), признак первой тройки (`selected`), название, номер рецепта обложки в комплекте `artifacts/stella-polza-kit` (`recipeId`) и тематика видео, которой жанр соответствует (`theme`).

Соответствие «тематика видео — жанр обложки»:

| Тематика видео | Жанр обложки |
|---|---|
| Наука | SCI-FI |
| Культура и образование | HISTORY |
| Медиа и шоу | COMEDY |
| Музыка | MUSICLE |
| Игры и авто | BOEVIK |
| Спорт | DRAMA, HORROR |
| Новости и бизнес | DETECTIVE |
| Кино | FANTASY, ADVENTURE |

Очки жанрам дают первые два ответа, по отдельной таблице:

| Ответ | +2 | +1 |
|---|---|---|
| 1.1 Новый сериал, который все обсуждают | FANTASY | HORROR |
| 1.2 Стендап или что-нибудь смешное | COMEDY | BOEVIK, MUSICLE |
| 1.3 Интервью с интересным человеком | HISTORY | DRAMA |
| 1.4 Документалку или научпоп | SCI-FI | ADVENTURE, DETECTIVE |
| 2.1 Драйвовый | BOEVIK, ADVENTURE | — |
| 2.2 Захватывающий | DRAMA, HORROR | — |
| 2.3 Познавательный | DETECTIVE | HISTORY, SCI-FI |
| 2.4 Расслабляющий | MUSICLE | FANTASY, COMEDY |

Жанры названы как рецепты обложек в комплекте: `SCI-FI` и `MUSICLE` — это «SCI FI» и «MUSICAL» из исходных таблиц.

Правило количества — решение Стеллы, его стоит подтвердить: берутся три лучших жанра, по одному видео с обложкой на каждый; жанры с равными очками разыгрываются случайно, один раз на посетителя. В исходных таблицах есть очки жанров, но не сказано, сколько жанров и видео брать. Очки есть минимум у трёх жанров при любых ответах, поэтому видео никогда не назначается жанру без очков.

Жанры считаются независимо от того, что стало с фото. Обложку с образом посетителя можно сделать, только когда `photo.status` равен `accepted`: при `skipped` и `unavailable` снимка нет.

## Тематики: что важно знать

Очки дают только первые два ответа: +2 одной тематике и +1 другой, всего шесть очков на посетителя. Третий ответ и фото на очки не влияют.

- Тематики с равными очками стоят в случайном порядке, который разыгран для этого посетителя один раз. В половине сочетаний ответов очки ложатся 2, 2, 1, 1 — тогда третья тематика выбрана случайно из двух с одним очком.
- Тематики с `score: 0` посетитель не выбирал: их порядок случаен и ничего не значит.

Названия тематик — как в таблице клиента «Метаданные VK Видео и MAX». Отдельных идентификаторов тематик в документе нет.

## Фото

| `photo.status` | Значение |
|---|---|
| `not-requested` | Фото не предлагалось: третий ответ не «Хочу стать героем VK Видео» |
| `skipped` | Посетитель нажал «Пропустить» |
| `accepted` | Посетитель одобрил снимок; `captureId` — номер снимка |
| `unavailable` | Посетитель согласился на фото, но снимка нет: камера недоступна или кадр не удался |

Снимок с номером `captureId` лежит в папке [PhotoStorage](../PhotoStorage/README.md): файлы `*_<captureId>.jpg` и `*_<captureId>.json`. Он записывается одновременно с итогом, отдельным запросом, поэтому может появиться на долю секунды позже файла итога.

## Что сохраняется, а что нет

- Сохраняется только тест VK Видео, пройденный до последнего выбора. Тест MAX итога не пишет.
- Работает только с dev-сервером (`.\scripts\stella.ps1 dev`) в локальном сценарии. В собранном приложении и на стенде этой папкой никто не пользуется: там ответы уходят в MASTER, и итог считает он.
- Запуск со ссылок предпросмотра, которые начинают с середины сценария (`?discovery=…`, `?reveal=…`), итога не пишет: за ними нет ответов.

## Внешний доступ

Это обычная папка с файлами, поэтому доступ к ней даётся средствами системы или сети:

- открыть папку как сетевой ресурс Windows только на чтение;
- синхронизировать папку на другой компьютер;
- перенести хранилище в уже общую папку: задайте переменную окружения `STELLA_RESULT_STORAGE` с полным путём до запуска dev-сервера.

Сам dev-сервер слушает только `127.0.0.1`. Адреса для чтения итогов по сети у него пока нет: итог забирают из папки.
